This game was originally part of a game called Rhythm Nights with Tappa, a game jam game made for the Freddit Game Jam.
Rhythm Test is exactly as expected. This is also packaged with RNwT's version of the Skill Star cue, though it doesn't work like the normal Skill Star cue.

Rhythm Test takes place outside the Tappa Pizzeria with YOU and the Tappa Cutout.
The cutout makes an amount of cowbell noises (the KtB cue), then a different cowbell cue followed by a hit noise (the pattern cue).
The hit noise is when the input happens, which can be either an A/+ input or just an A input.
